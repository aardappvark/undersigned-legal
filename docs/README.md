# undersigned-legal/docs

GitHub Pages source for `https://aardappvark.github.io/undersigned-legal/`.
Cloned from the RentBack Sol legal pack (`../../RentBack Sol/rentbacksol-legal/`,
8-page shape) on 8 September 2026 and adapted for Undersigned per
`LEGAL_FRAMEWORK_FOR_NEW_DAPPS.md` and `Undersigned/docs/LEGAL_GATES.md`.

## Outstanding before submission

- **`favicon.png` is a placeholder.** It is a direct copy of RentBack Sol's
  512×512 icon, not Undersigned's own. Per the fleet icon rule (one 512
  source drives the store icon, launcher layers, this legal favicon — which
  is also the MWA identity icon shown in the wallet approval sheet — and the
  store banner), replace this file with Undersigned's final 512×512 icon
  source before the first real sign-in on a device and before any dApp Store
  submission. See `feedback_dapp_icon_is_the_actual_icon.md` in memory.
- The `.well-known/security.txt` referenced in `terms.html`'s Support,
  Changes and Discontinuation section does not exist yet (same gap as the
  RentBack Sol template it was cloned from — not new to this clone).
- English only. The fleet's 28-language parity requirement was explicitly
  skipped for this pack per the owner's instruction.
